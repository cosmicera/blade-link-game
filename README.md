# 블레이드 링크 — 이음시 검술 리그

브라우저에서 실행하는 1인용 TCG 플레이테스트 프로토타입입니다. 소드걸스의 캐릭터·추종자·검식 카드 구분과 전장 중심의 대전 흐름을 참고했습니다. 카드 수치와 승패 조건은 게임 화면의 시범 규칙에 적힌 기본값으로 동작합니다.

시즌 1 카드풀은 추종자 36장과 검식 16장으로 구성됩니다. 로비의 **덱 편성** 화면에서 선택한 진영의 보유 카드 중 추종자 20장과 검식 10장, 총 30장을 직접 골라 저장합니다. 일반 카드는 덱당 최대 3장, 총수·협동조합 대표 추종자는 1장까지 넣을 수 있습니다. 저장한 덱은 브라우저에 보관되고 다음 대전에 사용됩니다. 대표 캐릭터는 별도 선택 카드입니다.

## 실행

index.html을 브라우저에서 열면 됩니다. 로컬 서버를 쓰려면 이 폴더에서 다음 명령을 실행한 뒤 http://localhost:8000 으로 접속하세요.

    python3 -m http.server 8000

## GitHub Pages

`main` 또는 `master` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 게임 파일을 자동 배포합니다. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택해야 처음 배포가 시작됩니다. GitHub Free에서 Pages를 무료로 쓰려면 저장소를 공개로 설정해야 하며, 배포된 사이트도 인터넷에 공개됩니다.

## 클래식 모드

- 대표 캐릭터의 라이프는 30입니다. 양쪽 손패는 라운드 시작에 5장까지 채워집니다.
- 기업별 방향은 아웃프라웨어의 회복·생장, 셀파스의 가속·정비, 남극성의 방어·반격, 언벡의 회수·우회입니다. 사이즈 4 추종자는 더 큰 공방체나 전장 전체에 영향을 주는 능력을 받는 대신 파괴 시 대표 라이프 4를 잃습니다.
- 부서명은 소속을 표시하는 태그입니다. 같은 부서 카드가 모여도 자동 보너스는 없으며, 카드 설명에 ‘연계 능력’이 적힌 일부 카드만 같은 부서 동료가 있을 때 고유 효과를 발동합니다.
- 카드 능력의 드로우는 손패 5장 제한을 넘기지 않습니다. 종자 저장고와 잔향의 호흡은 드로우와 함께 다음 라운드 사이즈 보너스를 줍니다. 추종자 능력의 회수·기록 효과는 손패 채우기를 대체하거나 라운드 사이즈를 높입니다.
- 매 라운드 코인 토스로 선공을 정합니다. 선공부터 양쪽 대표 캐릭터의 라운드 시작 능력이 발동하고, 이어 각 추종자의 라운드 시작 능력이 전장 슬롯 순서로 발동합니다.
- 추종자와 검식은 모두 최대 5칸 전장에 놓입니다. 기본 사이즈 한도는 10이며, 전장에 남은 추종자의 사이즈는 다음 라운드에도 점유합니다.
- 검식은 손패에서 전장에 배치한 뒤 전투 단계에서 발동합니다. 양쪽 검식이 모두 발동한 뒤 추종자 전투가 시작되고, 검식은 발동 후 버림 더미로 이동합니다.
- 검식 발동 순서와 각 플레이어의 추종자 공격 순서는 무작위입니다. 행동은 선공부터 양쪽이 번갈아 실행하며, 공격 대상도 상대 추종자 중 무작위로 정합니다.
- 대상 추종자가 공격을 견디면 방어전 능력을 발동하고 반격합니다. 전투 피해는 방어력만큼 줄어들며 최소 피해는 1입니다.
- 보호막 효과는 별도 수치 대신 해당 전투 동안의 방어력 상승으로 처리합니다.
- 상대 전장에 추종자가 없으면 공격 추종자는 자기 사이즈만큼 상대 대표에게 피해를 줍니다. 추종자가 파괴되면 그 소유자의 라이프가 해당 카드 사이즈만큼 감소합니다.
- 승패가 나지 않으면 다음 라운드로 자동 진행합니다. 카드가 모두 소진되면 패배합니다.

## 조작

손패 카드를 한 번 클릭하면 정보를 확인하고 더블클릭하면 전장에 배치합니다. 전장에 놓인 내 카드를 배치 단계에서 더블클릭하면 손패로 회수합니다. 손패 카드 선택 후 아래의 배치 버튼을 눌러도 됩니다. 전투 시작 버튼 또는 Space 키로 AI의 배치를 확정하고 라운드 전투를 진행합니다.

손패 좌측에는 카드 무덤, 우측에는 아직 뽑지 않은 덱을 표시합니다. 우측 카드 정보에서 캐릭터 일러스트 전체와 카드 능력치를 확인할 수 있고, 전투 기록은 패널 안에서 스크롤하거나 펼쳐 볼 수 있습니다.

전투 중에는 공격 대상과 능력의 영향을 받는 카드에 표식이 나타나며, 검격·파괴·무덤 이동 연출이 이어집니다. 덱에서 손패로 카드를 뽑을 때는 카드가 뒤집혀 나타납니다. 대표 캐릭터 배너를 선택하면 우측에 해당 캐릭터의 라이프와 능력이 표시됩니다.

## 파일 구성

- index.html, styles.css, main.js: 화면과 조작
- data.js: 기업, 대표 캐릭터, 추종자, 검식 카드 정의
- engine.js: 덱 구성, 라운드 처리, 카드 능력, 전투 판정
- assets/cards/: 게임에서 사용하는 카드 일러스트
- assets/card-art-index.json: 이미지 원본 경로와 seed 기록

대표 캐릭터는 옵시디안에 저장된 선택 일러스트를 사용했습니다. 유란은 후보 2번을 선택했습니다. 시즌 1 추가 추종자 20명의 게임 일러스트는 `assets/cards/expansion/`에 고정해 배포하며, 이미지 파일명과 seed는 `follower-expansion.js` 및 Obsidian 선택 목록에 기록했습니다.

## 신규 추종자 후보 선택

신규 인물 20명(기업별 5명)을 `follower-expansion.js`에 추가했습니다. 덱 편성은 추종자 일러스트 선택 페이지와 분리되어 카드풀에서 직접 진행합니다. 후보 비교용 `art-selection.html`은 게임 배포본에서 제외합니다. 게임 카드 데이터는 `data.js`와 `follower-expansion.js`이며, 확장 카드 재생성은 `python3 scripts/build_game_follower_pool.py`로 합니다. 부서 연계 능력은 카드에 개별 조건으로 적혀 있습니다.
